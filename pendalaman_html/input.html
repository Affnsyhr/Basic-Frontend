Contoh Tipe Input HTML

Tipe Contoh Deskripsi
text Input teks yang berisi satu baris. Default jika tidak menentukan tipe.
number Input teks yang hanya mengizinkan format angka.
password Setiap karakter ditampilkan sebagai bintang.
email Input untuk format email. Jika salah format → error.
search Input untuk pencarian, biasanya ada ikon ✕ untuk clear text.
date Input untuk memilih tanggal dengan date picker.
time Input untuk menentukan waktu (jam/menit).
datetime-local Input gabungan tanggal dan waktu.
checkbox Pilih saya Input kotak centang.
radio A B Input pilihan (satu dari beberapa opsi).
range Input slider dengan rentang nilai.
color Input pemilih warna.
file Input untuk upload file.
submit Tombol untuk mengirim form.
hidden (tidak terlihat) Input tersembunyi, digunakan developer untuk menyimpan data tambahan.
