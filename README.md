````markdown
# Basic-Frontend with CSS

## 📘 Pengenalan CSS
Repository ini berisi **catatan dan latihan pribadi** dalam mempelajari **CSS (Cascading Style Sheet)** secara lebih mendalam melalui pelatihan Dicoding.  
Tujuan utama adalah memahami tidak hanya **dasar-dasar CSS**, tetapi juga **aturan struktur sintaksnya, teknik penerapan, konsep**, hingga **menerapkan dasar styling**, seperti **memberikan warna teks pada sebuah teks**.

---

## 🎯 Tujuan Pembelajaran
- Memahami struktur sintaks CSS.  
- Mengenal **teknik penerapan** CSS pada HTML.  
- Memahami **konsep inheritance, group selector, dan rule order**.  
- Menerapkan **dasar styling** seperti mengubah warna teks, background, font, dan layout.  

---

## 📝 Menulis Aturan Styling
CSS memiliki dua bagian utama:
1. **Selector** → identitas elemen HTML yang akan diberikan styling.  
2. **Deklarasi** → instruksi yang berisi properti dan nilainya.  

````

## 📌 Cara Penerapan CSS

### 1. Inline Style

CSS ditulis langsung di dalam atribut `style` pada elemen HTML.


### 2. Embedded Style Sheet

CSS ditulis di dalam elemen `<style>` pada file HTML, biasanya diletakkan di bagian `<head>`.

---

### 3. External Style Sheet

CSS ditulis di file terpisah dengan ekstensi `.css`, lalu dipanggil dengan `<link>`.

---

### 4. Imported Style Sheet

Memanggil file CSS lain dengan `@import` di dalam file CSS utama.

---

## 📊 Kesimpulan

* Untuk latihan cepat → gunakan **Inline** atau **Embedded**.
* Untuk proyek nyata dan skala besar → gunakan **External Style Sheet**.
* Untuk manajemen modular → bisa gunakan **@import**, tapi tetap prioritaskan `<link>`.
