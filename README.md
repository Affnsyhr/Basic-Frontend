# 📘 Pendalaman HTML

Repository ini berisi **catatan dan latihan pribadi** dalam mempelajari **HTML (HyperText Markup Language)** secara lebih mendalam melalui pelatihan Dicoding.  
Tujuan utama adalah memahami tidak hanya **dasar-dasar HTML**, tetapi juga **elemen semantik, atribut, best practices,** serta integrasi dengan **CSS dan JavaScript**.

---

## 🎯 Tujuan Pembelajaran
- Memahami struktur dasar dokumen HTML.  
- Mengenal perbedaan antara **elemen block dan inline**.  
- Mempelajari **semantic HTML** untuk membuat halaman yang lebih terstruktur.  
- Menggunakan atribut HTML dengan baik (**multiple attributes, global attributes, event attributes**).  
- Menguasai **form dan input element** untuk interaksi dengan pengguna.  
- Mempelajari penggunaan elemen **multimedia** (image, audio, video).  
- Mengetahui praktik terbaik (**best practices**) dalam menulis HTML.  

---

## 📂 Struktur Belajar

### 📝 Dasar Elemen
- **Paragraf** → `<p>` digunakan untuk teks.  
- **Heading** → `<h1>` hingga `<h6>` untuk judul dan subjudul.  
- **List**  
  - `<ul>` unordered list (bullet).  
  - `<ol>` ordered list (angka).  
  - `<li>` item dalam list.  
- **Gambar** → `<img src="..." alt="...">` *(wajib gunakan `src`, disarankan `alt`)*.  

### 🔤 Formatting Text
- Kutipan: `<blockquote>`, `<q>`  
- Teks khusus: `<em>`, `<strong>`, `<mark>`  
- Sub/Superscript: `<sub>`, `<sup>`  
- Line break: `<br>`  

### 📂 Semantic HTML
- **Struktur halaman**: `<header>`, `<footer>`, `<main>`, `<nav>`  
- **Konten**: `<article>`, `<section>`, `<aside>`  
- **Media & caption**: `<figure>`, `<figcaption>`  

### 📋 Formulir & Input
- **Form wrapper**: `<form action="..." method="...">`  
- **Input**: `<input type="text|email|password|...">`  
- **Textarea**: `<textarea>` untuk teks panjang.  
- **Label**: `<label for="id">` terhubung dengan input.  
- **Button**: `<button type="submit">Submit</button>`  

### 📑 Tabel
- **Dasar**: `<table>`, `<tr>`, `<td>`, `<th>`  
- **Spanning**: `rowspan`, `colspan` untuk menggabung sel.  

### 🔣 Special Characters
- Non-breaking space → `&nbsp;`  
- Copyright → `&copy;`  
- Trademark → `&trade;`  
- Less than → `&lt;` , Greater than → `&gt;`
